title=Zbd Combat Lock
description=Tap Left Ctrl once to enter Project Zomboid's native aiming stance, then tap it again to return to normal controls. Press F8 to disable or re-enable Combat Lock during the session.
description=
description=Features:
description=- Persistent mouse aiming while moving with WASD
description=- Native attacks, targeting, animations, stamina, range and damage
description=- Small on-screen indicator while combat mode is active
description=- Configurable enable/disable action, with F8 as the default
description=- Native hold-to-aim controls whenever Combat Lock is disabled
description=- Client-side implementation with no dependencies
description=
description=Important: the Aim action must be bound to Left Ctrl. The Zbd Combat Lock action can be remapped in the game's key bindings. While combat mode is active, the left mouse button remains dedicated to combat. Toggle combat mode off before using inventory and other left-click interfaces.
description=
